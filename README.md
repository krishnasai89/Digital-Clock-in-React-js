# Digital-clock

## Prerequisites
- Node.js
- npm
- 
## Installation
1.Clone the repository:
```cmd
git clone https://github.com/krishnasai89/Digital-Clock-in-React-js.git
cd Digital-Clock-in-REact-js
```
2.Install the dependencies:
```cmd
npm start
```
## Usage
1.Start the development server:
```cmd
npm start
```
2.Open http://localhost:3000 to view it in the browser.
